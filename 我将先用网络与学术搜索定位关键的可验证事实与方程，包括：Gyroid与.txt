# Technical framework and quantitative design outputs
## 1) Implicit surface blending for a G–FKS hybrid with functional grading
- Level-set (implicit) equations (unit-cell-scaled form):
  - Gyroid (Schoen-Gyroid) level set:
    Φ_G(x,y,z) = cos(x) sin(y) + cos(y) sin(z) + cos(z) sin(x) − C = 0, where C controls porosity; scale to a physical period a by replacing x→2πx/a, etc.[^1] 
  - Fischer–Koch S (FKS) level set:
    Φ_FKS(x,y,z) = cos(2x) sin(y) cos(z) + cos(x) cos(2y) sin(z) + sin(x) cos(y) cos(2z) − C = 0 (C as a level-set constant when used in the same “f(x,y,z)=C” form)[^1].
- Functional grading via a spatially varying level-set constant:
  - Use a graded level-set constant C(x) (or C(x,y,z)) to vary the local porosity across the domain (e.g., core-to-shell). For Gyroid, porosity φ is directly controlled by the level-set constant C; altering C spatially controls φ(x) and pore size/shape (graded TPMS)[^3] [^1].
- C1-continuous blend (implicit field composition) to transition from Gyroid core to FKS shell:
  - Define a normalized transition parameter s(x)∈[0,1] across a finite-thickness blending band normal to the core–shell interface (s=0 at Gyroid side, s=1 at FKS side).
  - Choose a C1 weighting w(s) built from cubic polynomials used for implicit blending that ensure gradient continuity. A classical C1 form is (equivalent to a “smoothstep” family) in normalized distance r/R:
    F_cub2(r) = 2 (r/R)^3 − 3 (r/R)^2 + 1 (C1 continuous)[^2].
  - For an interpolation weight decreasing from 1→0 across the band, set w(s)=2 s^3 − 3 s^2 + 1 (note: s plays the role of r/R), which has w(0)=1, w(1)=0 and w′(0)=w′(1)=0 ensuring C1 blending[^2].
  - The graded, blended level set:
    Φ_H(x,y,z) = w(s(x))·Φ_G(x,y,z; C_G(x)) + [1 − w(s(x))]·Φ_FKS(x,y,z; C_FKS(x)) = 0
    with C_G(x) and C_FKS(x) chosen to achieve the target local porosity on each side of the transition band (see below).
  - Remarks on minimizing stagnant zones: C1 weighting ensures gradient continuity across the band (no kinks in ∇Φ), which reduces abrupt curvature/metric jumps that can generate recirculation pockets. Using a monotone w(s) and a transition aligned with the main perfusion direction further reduces separated-flow regions[^2].
- Relating target porosity to the level-set constant (Gyroid example):
  - For Gyroid, relationships between C and porosity φ, pore size, and specific surface can be calibrated; e.g., φ(C) can be expressed and used to set C(x) for a desired φ(x). The “Permea-Design” framework gives explicit C–φ relationships and shows how changing C alters porosity and pore size, which can be extended to graded fields C(x)[^3].
Outputs (transition equations and parameters):
- Gyroid core: Φ_G = cos(2πx/a) sin(2πy/a) + cos(2πy/a) sin(2πz/a) + cos(2πz/a) sin(2πx/a) − C_G(x) = 0[^1] [^3] 
- FKS shell: Φ_FKS = cos(4πx/a) sin(2πy/a) cos(2πz/a) + cos(2πx/a) cos(4πy/a) sin(2πz/a) + sin(2πx/a) cos(2πy/a) cos(4πz/a) − C_FKS(x) = 0 (scaled by a)[^1]
- Blend: Φ_H = w(s) Φ_G + [1−w(s)] Φ_FKS = 0 with w(s)=2 s^3 − 3 s^2 + 1 (C1), s(x)∈[0,1][^2]
- Functional grading: pick C_G(x), C_FKS(x) to realize φ(x). Example (Gyroid): use a calibrated φ(C) curve to set C(x) for a target φ(x) profile[^3].
## 2) Metabolic scaling and perfusion design for 1×10^12 neurons in a 25 L mass
- Oxygen/metabolic anchor:
  - A standard cerebral metabolic rate of oxygen (CMRO2) in normal adult human brain tissue is ≈3.5 ml O2 per 100 g brain per minute[^16].
  - Evidence supports an approximately conserved per-neuron energy budget across mammals and activity levels, partitioned into signaling and nonsignaling ATP usage (per-neuron ATP rates reported)[^12]. This justifies scaling transport demands with neuron number as a first-order design rule, recognizing that absolute per-neuron power depends on actual activity in this synthetic system.
- Scaling to 25 L biological mass:
  - If the 25 L scaffolded tissue is engineered to brain-like metabolic intensity (assumption for sizing), the corresponding O2 consumption rate is:
    Q̇_O2 ≈ 3.5 ml O2 / (100 g·min) × (25,000 g) = 875 ml O2/min (at standard conditions; exact conversion to moles depends on T,P – Data unavailable here).
  - Note: The actual metabolic rate for “1×10^12 neurons” depends on per-neuron activity and glia; Hyder et al. report per-neuron nonsignaling ATP demand P_ns,N ≈ 9.20×10^8 ATP/neuron/s, with additional signaling cost per spike (Ps ≈ 4.81×10^9 ATP/spike·neuron)[^12]. Converting ATP flux to power uses ΔG_ATP; under standard biochemical conditions ΔG° ≈ −28 to −33.5 kJ/mol (cellular ΔG can be larger by context)[^13]. If the user provides intended average firing rates, one can convert these to W/neuron and then check consistency with the oxygen supply target.
- Required total surface area and void fraction (framework):
  - Let the volumetric O2 demand be Ṽ_O2 (mol O2/s per m^3). For a perfused porous medium, the required interfacial area A to deliver oxygen by convection–diffusion with an interfacial mass-transfer coefficient k_L and driving concentration difference ΔC is:
    A_required = Q̇_O2 / (k_L ΔC_O2)
    where ΔC_O2 = C*_O2(37°C) − C_bulk (Data unavailable: need O2 solubility at 37 °C; not retrieved above).
  - Alternatively, to minimize diffusion-limited regions: impose a diffusion length L_d not exceeding a threshold (e.g., L_d ≤ √(D_O2 τ), where τ is the allowable time to deplete a local reservoir at demand ṽ_O2). With D_O2 ≈ 2.0×10^−9 m^2/s in water at room temperature[^15] (37 °C value is not extracted here — Data unavailable), one can set a target specific surface S/V (m^2/m^3) to hold typical half-distances to the nearest perfused channel ≤ L_d. The Permea-Design approach allows choosing C(x) to tune porosity φ and hence S/V locally[^3].
  - Specific void fraction (porosity φ): determine φ that achieves a permeability high enough for the target perfusion rates while maintaining sufficient S/V for mass transfer. FKS vs Gyroid permeability: a recent comparison in ceramic TPMS shows FKS scaffolds had only ~11% lower permeability but were ~32% stronger than Gyroid at matched geometry, suggesting FKS shells can sustain higher loads with comparable perfusion[^11]. Use φ(x) higher in the core (Gyroid) for maximal S/V and slightly lower (thicker walls) in the shell (FKS) for strength and heat exchange.
